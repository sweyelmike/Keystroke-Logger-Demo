# GUI-Based Keystroke Logging Demonstration System

## 📌 Project Overview

This project demonstrates a simple, ethical keystroke logging system using a Python GUI. It captures keyboard events in a controlled environment and displays them in real-time. The system is designed strictly for **educational purposes**, helping students, educators, and cybersecurity enthusiasts understand keyboard event handling and GUI development.

> **⚠️ Ethical Warning:** This tool is intended for learning only. Never use keystroke logging software on any computer without explicit, written permission from the owner.

---

## ✨ Features

* **Graphical User Interface (GUI):** Built with Tkinter for a clean, user-friendly experience.
* **Real-Time Capture:** Instantly displays keyboard inputs within the application window.
* **Interactive Controls:** Includes "Click Me" and "Quit" buttons to demonstrate event interaction.
* **Safety-First Design:** Designed to operate as a visible application, ensuring transparency during demonstrations.

---

## 👥 End Users

* **Students:** Learn keyboard event handling, GUI construction, and cybersecurity basics.
* **Educators / Professors:** Use as a teaching aid for ethical hacking and input monitoring modules.
* **Cybersecurity Enthusiasts:** Understand the mechanics behind keystroke logging in a safe, ethical way.
* **Researchers / Trainers:** Demonstrate GUI-based input monitoring during workshops or seminars.

---

## 🛠️ Technologies Used

* **Language:** Python 3.x
* **GUI Framework:** `Tkinter`
* **Event Handling:** `pynput` (or `keyboard`)
* **Environment:** VS Code / PyCharm
* **OS Compatibility:** Windows, Linux, macOS
